Step-by-Step Tutorial

Getting Started in 3 Steps

1

Create a Tunnel in Cloudflare Zero Trust

Log in to the Cloudflare Zero Trust Dashboard. Go to Networks > Tunnels > Add a tunnel.

Select Cloudflared, enter a name, and under Install and run a connector, copy the --token value from the command line:

cloudflared.exe service install eyJhIjoiYmNmNGM3...
2

Install App & Paste Token

Install cloudflared-android.apk on your device. Open the app, paste your base64 token into the Tunnel Token field, and tap Connect Tunnel.

Grant Notification Permission and approve the prompt to Ignore Battery Optimizations so Android does not suspend the background service.

3

Route Inbound Public Hostname

Back in your Cloudflare dashboard under the Public Hostnames tab, configure a route pointing to your Android local service:

Public Hostname: mydevice.yourdomain.com
Service Type:    HTTP
URL:             localhost:8080

Traffic to https://mydevice.yourdomain.com is now routed directly and securely to your phone or tablet.

Device Settings

24/7 Background Execution Guide

Aggressive battery-saving algorithms in custom Android skins can kill background services. Configure your device manufacturer's settings for uninterrupted uptime:

Manufacturer / OS Menu Navigation Required Configuration
Google Pixel / AOSP Settings > Apps > Cloudflared > App battery usage Set to Unrestricted
Samsung (One UI) Settings > Battery > Background usage limits Add Cloudflared to Never sleeping apps
Xiaomi (HyperOS / MIUI) App Info > Battery saver & Autostart Select No restrictions and enable Autostart
OnePlus / Oppo / Realme App Info > Battery usage Enable Allow background activity and Allow auto-launch
Common Questions

Frequently Asked Questions

Does this application require root access?

No. Cloudflared for Android operates completely within the unprivileged Android application sandbox. It uses custom stdin descriptor redirection to provide DNS resolution natively without superuser rights.

Can I expose services running inside Termux?

Yes. Any web service, API, or socket bound to localhost or 127.0.0.1 in Termux can be accessed by the Cloudflared service and exposed through your public hostname.

How does this bypass CGNAT and mobile carrier firewalls?

Traditional hosting requires an open incoming port, which mobile carriers block via Carrier-Grade NAT (CGNAT). Cloudflared establishes outbound encrypted QUIC/HTTP2 connections to Cloudflare's edge network, completely eliminating the need for inbound ports.

Will this drain my device's battery?

The native engine is lightweight and consumes minimal CPU when idle. When configured with appropriate battery exemptions, it typically consumes under 2-3% of battery over a full 24-hour period.
